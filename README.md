# AutomateStack

Production-ready AI automation kits for people who ship alone.

## What this is

A static storefront. Products are digital kits delivered instantly after checkout.
The site is generated by `engine/build.py` from a single catalog object — no CMS, no database.

## Structure

```
engine/build.py   generator (stdlib only)
dist/             generated site, deploy target
```

## Build

```bash
python3 engine/build.py
```

Output: `dist/index.html`, `dist/p/<slug>.html`, `dist/sitemap.xml`, `dist/products.json`.

## Checkout

Payments are handled by a hosted checkout link (`checkout` in the catalog).
Replace `REPLACE_ME` before going live. No payment data touches this repo.
