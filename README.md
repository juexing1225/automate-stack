# AutomateStack

Production-ready AI automation kits for people who ship alone.

## What this is

A static storefront. Products are digital kits delivered instantly by Gumroad after
checkout. The site is generated by `engine/build.py` from a single catalog object —
no CMS, no database, no build step beyond one Python file.

## Structure

```
engine/build.py   generator (standard library only)
dist/             generated site, deploy target (repo root of the Pages branch)
kits/             kit generator, produces the zips sold on Gumroad
```

## Build

```
python3 engine/build.py     # -> dist/index.html, dist/sitemap.xml, dist/robots.txt, dist/products.json
python3 kits/build_kits.py  # -> dist/kits/*.zip, each verified before packing
```

`kits/build_kits.py` fails the build if any workflow has a dangling connection,
unbalanced JavaScript in a Code node, or a placeholder that the setup doc does not
list. The placeholder table in each `docs/SETUP.md` is generated from the workflow
files, so the docs cannot drift from what the buyer actually sees in n8n.

## Checkout

Payments are handled by Gumroad hosted checkout. The `checkout` field in the catalog
holds the product URL:

```
https://juexing.gumroad.com/l/lead-intake
https://juexing.gumroad.com/l/invoice-chaser
https://juexing.gumroad.com/l/content-repurposer
```

No payment data touches this repo. If `checkout` is empty, the buttons fall back to
an in-page note instead of dead-ending.
